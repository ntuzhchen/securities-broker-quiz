# 證券商業務員 題庫測驗系統 (Securities Broker Quiz)

依據 114 年證券商業務員資格測驗考試範圍建立的線上互動題庫測驗系統。

## 特色

- 📚 **全書 1,352 題收錄**：涵蓋法規篇、實務篇、投資篇、財析篇與 6 屆最新歷屆試題真題。
- 🎯 **即時評分與詳解**：點擊選項即時判定對錯，展開官方名師詳解。
- 📕 **錯題複習本**：自動收集答錯題目，支援單獨攻克弱點。
- 📱 **手機響應式設計**：完美支援手機直式與桌面寬螢幕，支援加入手機主畫面（PWA 體驗）。
- 💾 **多使用者進度儲存**：使用瀏覽器 `localStorage` 獨立保存作答進度。
